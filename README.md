# 🐍 Python Essentials 1 — Cisco Networking Academy
 
> Repositório criado ao concluir o curso **Python Essentials 1 (PE1)** da Cisco Networking Academy.
 
---
 
## 📋 Sobre o curso
 
O **Python Essentials 1** é o primeiro módulo da trilha de certificação em Python oferecida pela Cisco em parceria com o **Python Institute**. O curso cobre os fundamentos da linguagem, com foco em boas práticas e resolução de problemas reais.
 
**Carga horária:** ~30 horas  
**Certificação:** PCEP — Certified Entry-level Python Programmer  
 
---
 
## 📂 Conteúdo deste repositório
 
| `python_essentials_1.py` | Script completo com todos os tópicos do curso |
 
---
 
## 🗂️ Tópicos cobertos
 
### Módulo 1 — Introdução ao Python
- O que é Python e por que usá-lo
- Função `print()`, escape sequences, concatenação
### Módulo 2 — Tipos de dados, Variáveis e Operadores
- Tipos primitivos: `int`, `float`, `bool`, `str`, `None`
- Casting e conversão de tipos
- Operadores aritméticos, relacionais, lógicos e bit a bit
- Função `input()` e leitura de dados
### Módulo 3 — Estruturas Condicionais e Loops
- `if` / `elif` / `else` e operador ternário
- `while` com `else`
- `for` com `range()`
- Controle de fluxo: `break`, `continue`
### Módulo 4 — Coleções de Dados
- **Listas:** indexação, slicing, métodos, busca, ordenação
- **List comprehension** e listas 2D (matrizes)
- **Tuplas:** imutabilidade e slicing
- **Dicionários:** chaves, valores, iteração
- **Conjuntos (sets):** operações de união, intersecção e diferença
### Módulo 5 — Funções
- Definição, parâmetros e retorno
- Parâmetros padrão e argumentos por palavra-chave
- Escopo local vs global
- **Recursão:** fatorial, Fibonacci, soma
### Módulo 6 — Exceções
- `try` / `except` / `else` / `finally`
- Exceções comuns: `ValueError`, `ZeroDivisionError`, `TypeError`, `IndexError`, `KeyError`
- Boas práticas no tratamento de erros
